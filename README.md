# Burp Suite Web Security Lab

This project demonstrates a hands-on web security lab using Burp Suite in an authorized testing environment.

## Objectives

- Configure Burp Suite Proxy
- Intercept browser HTTP/HTTPS traffic
- Analyze GET and POST requests
- Review server responses
- Use Burp Repeater for manual request testing
- Perform basic parameter testing
- Document findings with screenshots

## Tools

- Kali Linux
- Burp Suite
- Web Browser
- GitHub
